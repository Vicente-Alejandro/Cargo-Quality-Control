# Security Policy

## Supported Versions

Currently, `cargo-qc` provides security updates only for the latest stable release. 
Since this is a CLI tool and not an internet-facing service, the attack surface is minimal. However, we take supply chain security and dependency vulnerabilities seriously.

| Version | Supported          |
| ------- | ------------------ |
| 0.6.x   | :white_check_mark: |
| < 0.6   | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability in `cargo-qc` or its dependencies, please report it via GitHub's private vulnerability reporting feature on the repository.

Alternatively, you can email `alejandrohidalgosh@email.com` directly. 

We will respond within 48 hours to acknowledge the report and provide an estimated timeline for the fix and disclosure.
